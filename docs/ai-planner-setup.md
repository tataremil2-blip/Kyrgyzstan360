# Настройка ИИ-планировщика

Код планировщика умеет работать в двух режимах:

- без `OPENAI_API_KEY` — безопасный локальный разбор очевидных параметров;
- с ключом — серверный вызов OpenAI Responses API и структурированный черновик программы.

В окружении production задаются:

```text
OPENAI_API_KEY=<серверный ключ проекта>
OPENAI_PLANNER_MODEL=gpt-4.1-mini
```

Ключ нельзя помещать в `NEXT_PUBLIC_*`, клиентский код или репозиторий. Вызов
происходит только из `app/api/planner/route.ts`. Ответ проходит фильтрацию
известных аэропортов и мест и проверку структуры программы до показа туристу.

Перед включением production нужно:

1. Создать отдельный API-ключ проекта с ограниченным бюджетом.
2. Задать месячный лимит расходов и лимит запросов на сервере или на уровне провайдера.
3. Проверить русский и английский запросы в тестовой среде.
4. Убедиться, что ответы остаются черновиками до проверки сезонности, дорог,
   границ, размещения и фактической стоимости.

Текущий код не включает ключ и поэтому автоматически не отправляет пользовательские
запросы во внешний ИИ-сервис.
